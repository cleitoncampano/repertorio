# Troca

`troca`

Corte ou esmaecimento simples entre cenas diferentes.

**Em HTML:** Fade do slide inteiro; usar quando nada continua de um slide para o outro.

## Receita com o motor

`<section class="slide" data-trans="esmaecer">` (esmaece) ou `data-trans="corte"` (seco, sem animação).

- Use quando nada continua de um slide para o outro. Corte seco tem força dramática depois de uma sequência de Morph.
