# Conexão

`conexao` · operação: agrupamento · pista: agrupamento

Linhas, setas e conectores ligando partes.

**Em HTML:** SVG path entre elementos com stroke-dasharray animado (desenho da linha).

**Combina com:** `hierarquia-de-leitura`, `simetria-e-eixo`, `dado-como-heroi`, `contraste-de-cor`, `similaridade`
