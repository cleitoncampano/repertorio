# Linha-guia

`linha-guia` · operação: sequencia · pista: espaco

Caminho, trilha ou linha do tempo que o olho segue.

**Em HTML:** SVG path com marcadores; desenhar a linha com stroke-dashoffset e acender cada ponto.

**Combina com:** `contraste-de-cor`, `camera-continua`, `revelacao-progressiva`, `numeracao`, `foco-seletivo`
