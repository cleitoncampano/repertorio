# Máscara de forma

`mascara-de-forma` · operação: diferenciacao · pista: caracteristica

Foto dentro de uma forma, letra ou silhueta.

**Em HTML:** clip-path (circle, polygon, path) ou mask-image com SVG.

**Combina com:** `tipografia-como-imagem`, `contraste-de-cor`, `camera-continua`, `hierarquia-de-leitura`, `dado-como-heroi`
