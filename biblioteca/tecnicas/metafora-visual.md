# Metáfora visual

`metafora-visual` · operação: previsao · pista: semantica

Dois conceitos fundidos numa imagem só; a imagem é o argumento.

**Em HTML:** Composição de recortes PNG; a ideia vem antes do código.

**Combina com:** `contraste-de-cor`, `foco-seletivo`, `isolamento`, `profundidade-em-camadas`, `camera-continua`
