# Numeração

`numeracao` · operação: sequencia · pista: semantica

Números grandes conduzem a ordem dos itens.

**Em HTML:** Contador CSS (counter-increment) em tipografia display; 01, 02, 03.

**Combina com:** `regiao-comum`, `grade-modular`, `contraste-de-cor`, `sangria-total`, `similaridade`
