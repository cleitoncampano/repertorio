# Tipografia como imagem

`tipografia-como-imagem` · operação: diferenciacao · pista: caracteristica

O texto é a própria imagem: gigante, recortado, preenchido por foto, contornado.

**Em HTML:** background-clip: text com foto; -webkit-text-stroke para contorno; letras saindo da tela.

**Combina com:** `profundidade-em-camadas`, `contraste-de-escala`, `camera-continua`, `eco-tipografico`, `contraste-de-cor`
